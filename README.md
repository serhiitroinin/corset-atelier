# Vesna — corset house design directions

Ten homepage design directions for a corset-first womenswear brand. Static HTML/CSS/JS, no build step.

- `index.html` — gallery of the ten directions plus the market research summary
- `designs/<slug>/index.html` — one self-contained page per direction
- `assets/img/<slug>/` — mock-up imagery (AI-generated via Codex; PNG originals are gitignored, JPGs are served)
- `gen.sh`, `run-all.sh` — image generation scripts; `BRIEF.md` — shared design brief

"Vesna", product names and prices are placeholders.
